# Changelog

## 1.0.0-rc.1 — Complete toolset (2026-10-28)

- Added AST-backed Python symbol retrieval, bounded streaming path discovery and NUL-delimited filenames.
- Added pytest/Vitest/npm/Cargo/Go/CI diagnostic profiles, explicit custom regex rules and adaptive output selection.
- Added opt-in raw-log SHA256 indices and exact verified recovery without rerunning commands.
- Added reversible project installation and optional, nonblocking checkpoint hooks for documented host events.
- Added offline OpenAI/Anthropic/Gemini usage imports with provenance and explicit billing attachments.
- Added exact optional offline text token counting with verified local vocabulary files.
- Added seeded paired task execution, independent grading, retries, provenance and original-task clustered uncertainty.
- Added twelve distinct local coding fixtures and 144 independently graded repeated trials, all passing.
- Added deterministic release archives, checksums, reviewed source registry, issue templates and security policy.
- Closed independent regression cases for user-file preservation, symlink escapes, mutable log verification and forged line indices.
- Actual billed model savings and a sixty-task independent live evaluation are not claimed.

## Unreleased — Local P0 hardening

- Exact excerpts reject invalid UTF-8 and preserve Unicode separators inside source lines.
- Search reports only paths on stdout; fallback search skips hidden files, binary files and symlinks.
- Audit discovers project configuration inside `.agents`, `.claude`, `.codex` and `.gemini`.
- Command capture drains oversized lines in bounded pieces, prioritizes diagnostics over summaries,
  preserves repeated messages and POSIX signal exits, and flags omitted binary or oversized lines.
- Raw logs are opened before command execution; displayed-byte counts include inserted newlines.
- Evaluation rejects incomplete pairs, malformed CSV rows, duplicate columns and fractional counts;
  failed attempts remain in billed totals and observed success losses produce a quality warning.
- Expanded local regression coverage from 10 to 27 tests. Live billing and host behavior remain unverified.
